## プロジェクト概要

本プロジェクトでは、Olistが公開しているデータを使用し、ブラジルのEコマースマーケットプレイスのパフォーマンスを分析します。

目的は、取引データを**ビジネスに活用できるインサイト**へ変換することであり、以下の領域に焦点を当てています。

* 売上・GMVパフォーマンス
* 顧客行動と顧客分布
* 商品・カテゴリーのパフォーマンス
* 支払い方法
* 配送効率
* 顧客満足度

プロジェクトでは、以下のエンドツーエンドの分析フローを実施しました。

**データ探索 → データクレンジング → 探索的データ分析（EDA） → SQL分析 → ビジネスインサイト → Power BIダッシュボード**

## ビジネス上の問い

### 売上パフォーマンス

* 総GMVはいくらで、時間の経過とともにどのように変化しているか？
* どの商品カテゴリーが最も大きな取引額を生み出しているか？
* どの州が売上に最も貢献しているか？
* どの支払い方法が支払総額に最も大きく貢献しているか？

### 顧客分析

* マーケットプレイスには何人の顧客がいるか？
* 顧客が最も集中している州はどこか？
* 注文金額はどのように分布しているか？

### 商品・カテゴリー分析

* どのカテゴリーの販売数量が最も多いか？
* どのカテゴリーの顧客評価が最も高いか？
* カテゴリーの取引額と最も強く関連している要因は何か？

### 物流・顧客満足度

* 平均配送時間はどの程度か？
* どの州で配送遅延が最も多いか？
* 配送遅延と顧客満足度にはどのような関係があるか？

## 用語に関する注記

プロジェクト全体で言及している**約R$1,359万**という数値は、**GMV（Gross Merchandise Value）**を表しています。これはマーケットプレイスを通じて取引された商品の**総取引額**です。

GMVは、プラットフォームの収益（Olistが各取引から得る手数料）とは異なります。そのため、GMVはOlistの利益やプラットフォーム収益を意味するものではありません。

本データセットにはコストや利益率に関する情報が含まれていないため、本プロジェクトではマーケットプレイス全体の取引規模を表す指標としてGMVを使用しています。

また、本プロジェクトで示している相関関係（例：販売数量と取引額、配送遅延とレビュースコアなど）は、あくまで**統計的な関連性であり、因果関係を示すものではありません**。相関関係は、2つの変数間の関係の強さや方向を示すものであり、因果関係を証明するものではありません。

# 主なインサイト

## 売上とGMV

* マーケットプレイスの**GMVは約R$1,359万**で、**112,650点**の商品が**99,441件**の注文で販売されました。
* **上位5カテゴリーで総GMVの40.27%**を占めており、売上が一部のカテゴリーに集中しています。
* 販売数量とカテゴリーの取引額には強い関連性（**相関係数0.95**）がある一方、平均価格と取引額の関連性はほぼありません（**相関係数0.02**）。
* これは、カテゴリーの取引額を説明する上で、**平均価格よりも販売数量の方がはるかに強く関連している**ことを示しています。

## 顧客と地域

* マーケットプレイスには**96,096人のユニーク顧客**が存在します。
* サンパウロ州は顧客全体の**41.98%**を占め、リオデジャネイロ州（**12.92%**）、ミナスジェライス州（**11.70%**）が続きます。
* SP・RJ・MGの3州だけで顧客全体の**66.61%**を占めており、ブラジル南東部への顧客集中が強いことが分かります。

## 配送とオペレーション

* 平均して、注文は予定配送日より**11.18日早く**配送されていました。
* 全体の配送遅延率は、**配送結果が確認できる注文の8.11%**でした。
* 極端な配送遅延は分析対象の約**1%**でした。
* 発生頻度は低いものの、極端な遅延は顧客体験に大きな影響を与える可能性があります。

## レビューと顧客満足度

* **57.78%のレビューが5つ星**であり、最も多い評価となっています。
* 配送遅延が発生した注文の平均レビュースコアは**2.57**で、時間通りに配送された注文では**4.29**でした（差は**1.72ポイント**）。
* 配送遅延とレビュースコアの相関係数は**-0.27**であり、配送遅延と顧客満足度の間に負の関連性が確認されました。

## 支払い

* クレジットカードは支払総額の**78.34%**を占め、最も主要な支払い方法でした。
* クレジットカード決済の**62.93%が3回以下の分割払い**でした。

## セラー

* マーケットプレイスには**3,095のセラー**が存在します。
* **上位10%のセラーが総売上の67.56%**を占めており、売上が一部のセラーに集中しています。
* セラーの販売数量と、平均レビュースコアまたは納期遵守率との間には、意味のある関連性は確認されませんでした。
* これは、このマーケットプレイスでは**販売面とオペレーション面のパフォーマンスが比較的独立した側面である**ことを示しています。

# ビジネス上の提案

### 1. 高パフォーマンスカテゴリーへの注力

GMVの40.27%が上位5カテゴリーに集中しているため、セラー獲得、在庫供給、プロモーション戦略において、これらのカテゴリーを優先的に検討できます。

**成功指標の提案：** 上位5カテゴリーのGMVシェアを四半期ごとに追跡し、成長が他のカテゴリーを過度に圧迫していないか確認する。

### 2. 地域別の物流パフォーマンスを監視

全国平均である**8.11%（配送結果が確認できる注文における遅延率）**を上回る州については、セラーの所在地、配送距離、配送業者のパフォーマンスなど、根本原因を調査することが推奨されます。

**成功指標の提案：** 最もパフォーマンスの低い州の遅延率を、2四半期以内に全国平均の**2ポイント以内**に縮小する。

### 3. 極端な配送遅延を調査

極端な遅延（約1%）は稀ですが、レビュースコアの大幅な低下と関連しています。

州・セラー・カテゴリー別に監視することで、繰り返し発生する問題点を特定できます。

**成功指標の提案：** 顧客満足度への影響を踏まえ、極端な遅延の発生率を半減させる。

### 4. セラー集中リスクの軽減

上位10%のセラーが売上の**67.56%**を占めていることは、少数の主要セラーを失った場合に売上へ大きな影響を及ぼしうるという集中リスクを意味します。

**成功指標の提案：** 中規模セラー（売上上位10〜50%層）の売上シェアを今後1年で増加させ、セラーベースの分散を図る。

# 分析上の限界

本分析には、今後活用する際に留意すべき以下のような限界があります。

* **分析対象期間：** データセットは特定の過去期間のみを対象としており、季節性（年末商戦やプロモーション期間など）を完全には反映できていない可能性があります。
* **原価・マージンデータの欠如：** GMVは取引額を示すものであり、プラットフォームの利益ではありません。カテゴリーやセラーの優先順位に関する提案は、商業的な意思決定の前に実際のマージンデータで検証する必要があります。
* **顧客の生涯データの欠如：** リピート購入やコホート行動の分析は、単一の過去データスナップショットに基づく範囲に限定されます。
* **地理的粒度：** 州単位の分析では、サンパウロ州のような大きな州の中の都市・地域レベルの物流差異が見えにくくなる可能性があります。

# まとめ

本プロジェクトでは、データの探索・クレンジングからSQL分析、ビジネスインサイトの導出、インタラクティブなダッシュボード開発まで、**エンドツーエンドのデータ分析プロセス**を実施しました。

分析を通じて、**カテゴリー別のGMV集中、顧客の地域的集中、セラーへの売上依存、配送パフォーマンスと顧客満足度の関係**など、マーケットプレイスの重要な特徴を明らかにしました。

Python、SQL、Power BIを活用し、取引データを**ビジネス上の意思決定につながるインサイトと提案へ変換するプロセス**を実践したプロジェクトです。
